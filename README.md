# YC Studio: bản phát hành

Repo này chỉ chứa bản cài đặt của YC Studio (bản native cho Windows). Mã nguồn nằm ở repo riêng.

**Tải bản mới nhất:** vào [Releases](../../releases/latest) và tải `YC-Studio-Setup-<phiên bản>.exe`, rồi chạy file đó.

- Cần Windows 10 trở lên (64-bit).
- Setup cài app cho người dùng hiện tại, tạo icon ngoài Desktop và trong Start menu, và có mục gỡ cài đặt trong Settings > Apps.
- App đã cài sẽ tự báo khi có bản mới (nút **Cập nhật** trên thanh trên). Mỗi bản cập nhật đều được kiểm chữ ký số trước khi cài.

`latest.json` trong mỗi bản phát hành là tệp app đọc để biết phiên bản mới nhất; đừng sửa tay.
